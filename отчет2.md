## 1. Семь замечаний — как исправлены

| # | Замечание | Решение |
|---|---|---|
| 1 | img-запросы без Authorization | Cookie-сессии: `POST /api/auth/login` проверяет токен (`hmac.compare_digest`), создаёт сессию в новой таблице `auth_sessions`, ставит `HttpOnly; SameSite=Strict` cookie. `<img>` несёт cookie автоматически. Bearer остаётся для API/MCP/клиентов. Logout, TTL 30 дней, purge просроченных |
| 2 | missing при неполном обходе | Скanner ведёт `walk_errors` и `skipped_dirs`. Любая ошибка `scandir`/`stat` → фаза missing **не выполняется вовсе** (`missing_check: skipped_incomplete_walk` в результате job). Файлы под исключёнными/скрытыми/reparse/циклическими каталогами **никогда** не помечаются missing. Отмена job тоже прерывает до фазы missing |
| 3 | неоднозначный marker | `match_identity`: >1 записи с одним marker → `None` + warning, только ручной rebind. Clone-детекция: если маркер уже привязан и старый якорь всё ещё жив с тем же маркером → `409 conflict`. В `refresh` второй маунт с той же идентичностью не перепривязывает том, а пишет `volumes.identity_warning` |
| 4 | миграции | `database/migrations/0001_initial.sql`, `0002_auth_sessions.sql`; раннер по `PRAGMA user_version`, каждый шаг в транзакции (`BEGIN…PRAGMA user_version=N…COMMIT`, откат при ошибке), проверка нумерации без пропусков. `schema.sql` заменён миграцией 0001 (дубля нет) |
| 5 | токен в URL | Убрано полностью: ни `?token=`, ни localStorage. Токен печатается **только в консоль** при LAN-старте (и `--show-token`), вводится в форму входа в UI. В URL и access-логах секретов нет |
| 6 | follow_symlinks не работал |Cause: `is_dir(follow_symlinks=False)` для symlink-каталога возвращал False. Теперь при `follow=True` — `is_dir/stat(follow_symlinks=True)` + цикл-гард `(st_dev, st_ino)`; symlink наружу тома (`..`) пропускается; битые ссылки — skip, не ошибка обхода. При `False` — reparse пропускается и попадает в `skipped_dirs` |
| 7 | регистр путей Windows | `path_key()` (casefold на NT) для seen/prefix/дедупа root'ов; SQL `COLLATE NOCASE` в `get_image_by_path`; дедуп root'ов в сервисе. Ограничение: `NOCASE` — ASCII-фолдинг, документировано |

+import os, re
+from pathlib import Path
+from .errors import ServiceError

+class PathError(ServiceError):
+    def __init__(self, message: str): super().__init__("bad_request", message)
+
+def path_key(rel: str) -> str:
+    """Ключ сравнения путей: на Windows ФС регистронезависима."""
+    return rel.casefold() if os.name == "nt" else rel
+
+def safe_join(base: Path, rel: str) -> Path:
+    """Никаких абсолютных путей, дисков, '..', NUL; результат строго внутри base."""
+    if not isinstance(rel, str) or "\x00" in rel:
+        raise PathError("invalid relative path")
+    r = rel.replace("\\", "/")
+    if r.startswith("/") or re.match(r"^[A-Za-z]:", r):
+        raise PathError("absolute paths are not allowed")
+    parts = [p for p in r.split("/") if p not in ("", ".")]
+    if any(p == ".." for p in parts):
+        raise PathError("parent traversal is not allowed")
+    b = Path(os.path.normcase(str(base.resolve())))
+    p = Path(os.path.normcase(str(base.joinpath(*parts).resolve())))
+    if os.path.commonpath([str(p), str(b)]) != str(b):
+        raise PathError("path escapes registered root")
+    return p

+from __future__ import annotations
+import hmac, logging, secrets, time
+from datetime import datetime, timedelta, timezone
+from database import repository as repo
+from database.db import utcnow
+
+log = logging.getLogger("imagevault.auth")
+SESSION_COOKIE = "iv_session"
+SESSION_TTL_DAYS = 30
+
+def _fmt(dt: datetime) -> str:
+    return dt.strftime("%Y-%m-%dT%H:%M:%S.%f")[:-3] + "Z"
+
+class AuthService:
+    """Bearer-токен для API-клиентов + cookie-сессии для браузера (img не шлёт заголовки)."""
+    def __init__(self, db, cfg):
+        self.db, self.cfg = db, cfg
+
+    def login(self, token: str, user_agent: str | None = None) -> str | None:
+        if not self.cfg.auth_token:
+            return "auth-disabled"
+        if not hmac.compare_digest((token or "").encode(), self.cfg.auth_token.encode()):
+            time.sleep(0.5)
+            log.warning("failed login attempt")  # сам токен не логируется
+            return None
+        conn = self.db.conn()
+        repo.purge_expired_sessions(conn)
+        sid = secrets.token_urlsafe(32)
+        expires = _fmt(datetime.now(timezone.utc) + timedelta(days=SESSION_TTL_DAYS))
+        repo.create_session(conn, sid, expires, user_agent)
+        return sid
+
+    def logout(self, sid: str | None):
+        if sid:
+            repo.delete_session(self.db.conn(), sid)
+
+    def session_valid(self, sid: str | None) -> bool:
+        if not sid:
+            return False
+        conn = self.db.conn()
+        row = repo.get_session(conn, sid)
+        if not row:
+            return False
+        if row["expires_at"] < utcnow():
+            repo.delete_session(conn, sid)
+            return False
+        repo.touch_session(conn, sid)
+        return True
+
+    def request_authorized(self, request) -> bool:
+        if not self.cfg.auth_token:
+            return True
+        h = request.headers.get("authorization", "")
+        if h.startswith("Bearer ") and hmac.compare_digest(
+                h[7:].encode(), self.cfg.auth_token.encode()):
+            return True
+        return self.session_valid(request.cookies.get(SESSION_COOKIE))
+
+    def status(self, request) -> dict:
+        return {"auth_required": bool(self.cfg.auth_token),
+                "authenticated": self.request_authorized(request)}

+def read_marker(anchor: str) -> str | None:

+        data = json.loads((Path(anchor) / MARKER_NAME).read_text(encoding="utf-8"))
+        v = data.get("imagevault_volume_uuid")

+    p = Path(anchor) / MARKER_NAME

+    if existing and existing != marker_uuid:
+        raise ServiceError("conflict", "volume already has a different ImageVault marker")
+    tmp = p.with_suffix(".tmp")

+                   encoding="utf-8")

+    return marker_uuid

+def _probe_windows(anchor: str) -> Identity:
+    import ctypes
+    from ctypes import wintypes
+    k32 = ctypes.windll.kernel32
+    guid_buf = ctypes.create_unicode_buffer(512)
+    guid = guid_buf.value if k32.GetVolumeNameForVolumeMountPointW(anchor, guid_buf, 512) else None
+    serial, maxcomp, flags = wintypes.DWORD(), wintypes.DWORD(), wintypes.DWORD()
+    fs_buf, label_buf = ctypes.create_unicode_buffer(256), ctypes.create_unicode_buffer(256)
+    ok = k32.GetVolumeInformationW(anchor, label_buf, 256, ctypes.byref(serial),
+                                   ctypes.byref(maxcomp), ctypes.byref(flags), fs_buf, 256)
+    if not ok and not guid:
+        raise OSError(f"volume not ready: {anchor}")
+    drive_types = {2: "removable", 3: "fixed", 4: "network", 5: "cdrom", 6: "ramdisk"}
+    return Identity(anchor=anchor, volume_guid=guid or None,
+                    fs_serial=f"{serial.value:08X}" if ok else None,
+                    label=(label_buf.value or None) if ok else None,
+                    fs_type=(fs_buf.value or None) if ok else None,
+                    media_type=drive_types.get(k32.GetDriveTypeW(anchor), "unknown"),

+def probe(path: str | Path) -> Identity:
+    p = Path(path).resolve()
+    if IS_WIN:
+        drive = os.path.splitdrive(str(p))[0]
+        if not drive:
+            raise ServiceError("bad_request", f"cannot determine drive for {path}")
+        return _probe_windows(drive + "\\")

+        raise OSError(f"not a directory: {p}")
+    st = p.stat()

+    if not IS_WIN:
+        return False

+def match_identity(ident: Identity, volumes: list[dict]) -> dict | None:
+    """marker -> GUID -> serial+label/fs. Любая неоднозначность => None (ручной rebind)."""
+    if ident.marker_uuid:

+        if len(c) == 1:
+            return c[0]
+        if len(c) > 1:
+            log.warning("ambiguous marker %s...: %d registry rows; manual rebind required",
+                        ident.marker_uuid[:8], len(c))
+            return None
+    if ident.volume_guid:
+        c = [v for v in volumes if v["volume_guid"] == ident.volume_guid]
+        if len(c) == 1:
+            return c[0]
+        if len(c) > 1:
+            log.warning("ambiguous GUID match for %s; manual rebind required", ident.anchor)
+            return None
+    if ident.fs_serial:
+        c = [v for v in volumes if v["fs_serial"] == ident.fs_serial
+             and (v["label"] == ident.label or v["fs_type"] == ident.fs_type)]
+        if len(c) == 1:

+def register_volume(db, path: str, create_marker=False, allow_system_marker=False) -> dict:
+    conn = db.conn()
+    ident = probe(path)
+    if create_marker and not ident.marker_uuid:
+        if is_system_drive(ident.anchor) and not allow_system_marker:
+            raise ServiceError("bad_request",

+        ident.marker_uuid = write_marker(ident.anchor, uuid.uuid4().hex)
+    volumes = repo.list_volumes(conn)
+    m = match_identity(ident, volumes)
+    now = utcnow()
+    if m:

+        if (ident.marker_uuid and m["marker_uuid"] == ident.marker_uuid
+                and os.path.normcase(m["anchor"] or "") != os.path.normcase(ident.anchor)):

+                old = probe(m["anchor"])
+            except (OSError, ServiceError):
+                old = None
+            if old and old.marker_uuid == ident.marker_uuid:
+                raise ServiceError("conflict",
+                                   "marker present on two mounts (cloned disk?); rebind manually")
+        repo.update_volume(conn, m["id"], **_ident_fields(ident),
+                           status="online", last_seen_at=now, identity_warning=None)
+        return repo.get_volume(conn, m["id"])
+    if ident.marker_uuid and any(v["marker_uuid"] == ident.marker_uuid for v in volumes):
+        raise ServiceError("conflict", "ambiguous marker in registry; rebind manually")
+    vid = repo.insert_volume(conn, {"id": uuid.uuid4().hex, **_ident_fields(ident),
+                                    "status": "online", "last_seen_at": now})
+    return repo.get_volume(conn, vid)
+
+def refresh_volumes(db) -> list[dict]:
+    conn = db.conn()
+    volumes = repo.list_volumes(conn)
+    matched: dict[str, str] = {}
+    anchors = enumerate_anchors() or [v["anchor"] for v in volumes if v["anchor"]]
+    for anchor in anchors:
+        try:
+            ident = probe(anchor)
+        except (OSError, ServiceError):
+            continue
+        m = match_identity(ident, volumes)
+        if not m:
+            continue
+        if m["id"] in matched:
+            msg = f"identity seen on multiple mounts: {matched[m['id']]} and {ident.anchor}"
+            repo.update_volume(conn, m["id"], identity_warning=msg)
+            log.warning("volume %s: %s", m["id"], msg)
+            continue
+        repo.update_volume(conn, m["id"], **_ident_fields(ident),
+                           status="online", last_seen_at=utcnow(), identity_warning=None)
+        matched[m["id"]] = ident.anchor
+    for v in volumes:
+        if v["id"] not in matched and v["status"] != "offline":
+            repo.update_volume(conn, v["id"], status="offline")
+    return repo.list_volumes(conn)
+
+def rebind_volume(db, volume_id: str, path: str, force=False) -> dict:
+    conn = db.conn()
+    v = repo.get_volume(conn, volume_id)
+    if not v:
+        raise ServiceError("not_found", "volume not found")
+    ident = probe(path)
+    if ident.marker_uuid and v["marker_uuid"] and ident.marker_uuid != v["marker_uuid"] and not force:
+        raise ServiceError("conflict", "marker mismatch; use force=true only if you are sure")
+    others = [x for x in repo.list_volumes(conn) if x["id"] != volume_id]
+    if match_identity(ident, others):
+        raise ServiceError("conflict", "path matches another registered volume")
+    if ident.marker_uuid and any(x["marker_uuid"] == ident.marker_uuid for x in others):
+        raise ServiceError("conflict", "ambiguous marker in registry; rebind manually")
+    fields = _ident_fields(ident)
+    if not ident.marker_uuid:
+        fields.pop("marker_uuid")
+    repo.update_volume(conn, volume_id, **fields, status="online",
+                       last_seen_at=utcnow(), identity_warning=None)
+    return repo.get_volume(conn, volume_id)

+from __future__ import annotations
+import logging, sqlite3, threading
+from contextlib import contextmanager
+from datetime import datetime, timezone
+from pathlib import Path
+
+log = logging.getLogger("imagevault.db")
+MIGRATIONS_DIR = Path(__file__).resolve().parent / "migrations"
+
+def utcnow() -> str:
+    return datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%S.%f")[:-3] + "Z"
+
+def _migrations() -> list[tuple[int, Path]]:
+    out = []
+    for f in sorted(MIGRATIONS_DIR.glob("*.sql")):
+        out.append((int(f.name.split("_", 1)[0]), f))
+    return out
+
+class Database:
+    """Одно соединение на поток; WAL; короткие транзакции; миграции по user_version."""
+    def __init__(self, path: Path):
+        self.path = Path(path)
+        self._local = threading.local()
+
+    def conn(self) -> sqlite3.Connection:
+        c = getattr(self._local, "c", None)
+        if c is None:
+            c = sqlite3.connect(self.path, timeout=5, isolation_level=None)
+            c.row_factory = sqlite3.Row
+            c.execute("PRAGMA foreign_keys=ON")
+            c.execute("PRAGMA busy_timeout=5000")
+            c.execute("PRAGMA synchronous=NORMAL")
+            self._local.c = c
+        return c
+
+    def init(self):
+        self.path.parent.mkdir(parents=True, exist_ok=True)
+        self.conn().execute("PRAGMA journal_mode=WAL")
+        self.migrate()
+
+    def migrate(self):
+        c = self.conn()
+        current = c.execute("PRAGMA user_version").fetchone()[0]
+        migs = _migrations()
+        if [n for n, _ in migs] != list(range(1, len(migs) + 1)):
+            raise RuntimeError("migration numbering must be sequential without gaps")
+        for n, f in migs:
+            if n <= current:
+                continue
+            sql = f.read_text(encoding="utf-8")
+            log.info("applying migration %04d (%s)", n, f.name)
+            try:
+                c.executescript("BEGIN IMMEDIATE;\n" + sql
+                                + f"\nPRAGMA user_version={n};\nCOMMIT;")
+            except Exception:
+                try:
+                    c.execute("ROLLBACK")
+                except sqlite3.Error:
+                    pass
+                log.exception("migration %04d failed, rolled back", n)
+                raise
+
+    @contextmanager
+    def tx(self):
+        c = self.conn()
+        c.execute("BEGIN IMMEDIATE")
+        try:
+            yield c
+            c.execute("COMMIT")
+        except BaseException:
+            c.execute("ROLLBACK")
+            raise
+
+    def backup(self, dest: Path):
+        dst = sqlite3.connect(dest)
+        try:
+            self.conn().backup(dst)
+        finally:
+            dst.close()

+    response.delete_cookie(SESSION_COOKIE, path="/")
+    return {"ok": True}

+@router.get("/status")
+def status(request: Request, svc=Depends(get_auth)):

+    logger.setLevel(logging.INFO)
+    logger.propagate = False
+    fmt = logging.Formatter("%(asctime)s %(levelname)s %(name)s: %(message)s")
+    fh = logging.FileHandler(cfg.logs_dir / "imagevault.log", encoding="utf-8")
+    sh = logging.StreamHandler()
+    for h in (fh, sh):
+        h.setFormatter(fmt)
+        logger.addHandler(h)
+
+def create_app(cfg: Config | None = None) -> FastAPI:
+    cfg = cfg or load_config()
+    setup_logging(cfg)
+    db = Database(cfg.db_path)
+    db.init()
+    jm = JobManager(db, workers=cfg.workers)
+    catalog = CatalogService(db, cfg)
+    auth = AuthService(db, cfg)
+    jm.register("scan_root", catalog.run_scan)
+    jm.register("thumbnail", catalog.run_thumbnail)
+
+    @asynccontextmanager
+    async def lifespan(app: FastAPI):

+        yield

+                  docs_url=None if cfg.auth_token else "/docs")

+    app.state.catalog, app.state.auth = catalog, auth

+    @app.exception_handler(ServiceError)

+                            status_code=HTTP_CODES.get(exc.code, 400))
+
+    @app.middleware("http")
+    async def auth_middleware(request: Request, call_next):
+        path = request.url.path
+        if cfg.auth_token and path.startswith("/api") and path not in AUTH_EXEMPT:
+            origin = request.headers.get("origin")
+            if origin and urlparse(origin).netloc != request.url.netloc:
+                return JSONResponse({"error": "forbidden_origin"}, status_code=403)

+# Архитектура ImageVault (v0.2.0, Этапы 0–1)
+
+## Слои
+Web UI / REST / (MCP позже) → `services/CatalogService` → `core/*` → `database/*` (SQLite WAL).
+Бизнес-логика не дублируется в интерфейсах. Состояние задач — только в SQLite.
+
+## Аутентификация
+- LAN включается явно (`--host` не loopback). Без токена не стартует в LAN.
+- Токен печатается только в консоль (`--show-token`), хранится в `data/config.json`.
+- Браузер: форма входа → `POST /api/auth/login` → HttpOnly `SameSite=Strict` cookie
+  (`auth_sessions` в БД, TTL 30 дней). `<img>` несёт cookie автоматически.
+- API-клиенты/MCP: `Authorization: Bearer <token>` (constant-time сравнение).
+- Проверка Origin при включённой авторизации. В URL секреты не передаются.
+- HTTP в LAN — только доверенная сеть; HTTPS/reverse proxy — Этап 8.
+
+## Миграции
+`database/migrations/NNNN_*.sql`, версия в `PRAGMA user_version`.
+Каждая миграция — одна транзакция (BEGIN…PRAGMA…COMMIT), откат при ошибке,
+нумерация без пропусков. Схема v0.1 = миграция 0001; 0002 = сессии + identity_warning.
+
+## Идентичность носителей
+Приоритет: marker UUID → Volume GUID → serial+label/fs_type.
+Любая неоднозначность (в т.ч. marker) → автосвязывание запрещено, только ручной rebind.
+Клон диска (маркер на двух живых маунтах) → 409 при регистрации, `identity_warning` при refresh.
+Маркер пишется только по явному запросу; на системный диск — с `allow_system_marker`.
+
+## Сканирование
+- Инкрементальность: size + mtime_ns; неизменённые файлы не трогаются.
+- missing проставляется ТОЛЬКО при полностью успешном обходе (`missing_check: complete`);
+  ошибки доступа → фаза missing пропускается; исключённые/скрытые/reparse/циклические
+  каталоги и их содержимое никогда не помечаются missing. Отмена job — до фазы missing.
+- follow_symlinks=False (по умолчанию): reparse points пропускаются.
+  True: обход с цикл-гардом (st_dev, st_ino); ссылки наружу тома пропускаются.
+- Windows: сравнения путей регистронезависимы (path_key + COLLATE NOCASE;
+  ограничение: NOCASE — ASCII-фолдинг).
+
+## Очередь задач
+Захват атомарным `UPDATE…RETURNING`; heartbeat; cancel кооперативный;
+пауза — уровень очереди; восстановление `running→pending` при старте.
+
+## Известные ограничения
+FAT/exFAT mtime 2s; смена буквы диска проверяется вручную на сменном носителе;
+POSIX-идентичность — dev-режим; токен в config.json открыто (локальный файл).
